# ADRs

Architecture Decision Records in this directory capture durable technical decisions for this repo.

## Naming

- use sequential numeric prefixes: `0001-short-title.md`
- keep titles about decisions, not tasks

## Suggested Sections

- `Status`
- `Context`
- `Decision`
- `Consequences`

## Scope

Record decisions that change how contributors should reason about architecture, deployment, data flow, or major UI surfaces.
