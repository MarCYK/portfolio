## Agent skills

### Issue tracker

Issues for this repo live in GitHub Issues via the gh CLI. See docs/agents/issue-tracker.md.

### Triage labels

This repo uses the default five-label triage vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See docs/agents/triage-labels.md.

### Domain docs

This repo uses a single-context layout: one root CONTEXT.md and one root docs/adr/ directory when those docs exist. See docs/agents/domain.md.
