# Target Website

## URL
https://finethought.com.au/

## Scope

### Pages to Replicate
- [x] Home page / landing experience
- [x] Shared navigation, footer, and page transitions
- [x] Reusable portfolio project/card sections inspired by the target site
- [ ] Secondary project detail pages if needed after the home page is complete

### Fidelity Level
- [ ] **Pixel-perfect** — exact match in colors, spacing, typography, animations
- [x] **High fidelity** — visually similar, same layout and feel, minor deviations OK
- [ ] **Structural** — same layout and components, custom styling acceptable

### In Scope
- Visual layout, spacing, and typography direction inspired by `finethought.com.au`
- Hero section and scroll-driven storytelling feel
- Component structure and interactions
- Responsive design for desktop, tablet, and mobile
- Portfolio content adapted to my own work, case studies, and personal brand
- Mock or static data where needed during the build

### Out of Scope
- Real backend / database
- Authentication
- Real-time features
- CMS integration on the first pass
- Full SEO optimization on the first pass
- Deep accessibility audit on the first pass
- Any copyrighted branding, copy, or client work that should be replaced with my own content

## Why
I want to use `finethought.com.au` as the design reference for my portfolio website because it has the kind of polished, modern, creative-developer presentation I want to emulate. The goal is to recreate the overall feel and interaction quality as a strong portfolio template, then replace all content with my own projects, writing, and branding.

## Customization Plans
- Replace all text, imagery, and project content with my own portfolio content
- Adjust colors, type scale, and brand details so the final site feels original
- Add my own About, Projects, and Contact content once the base template is working
- Keep the same premium creative-tech vibe, but tailor the final experience to my personal brand
